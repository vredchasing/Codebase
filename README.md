# Codebase

Codebase is a free, open-source collaborative development platform designed to accelerate workflows through powerful agentic workflows. Built to handle the entire software development process from idea to deployment.

---

### Custom IDE/Workspace

Codebase provides a custom IDE, designed with proven styles heavily inspired by industry giants such as VSCode and Cursor. Intuitive and familiar designs allow users to easily integrate themselves into Codebase's ecosystem.

### MCP - Model Context Protocol Layer

Allows users to integrate the core engine into different applications. Use our powerful agentic architecture, in any of your LLM applications and workspaces.

### Custom RAG Engine

Provides low cost embedding capabilities, with incremental updates via merkle trees. Users can efficently embed and retrieve across large repositories, allowing agents to quickly catch up to speed on your codebase. Utilizing KV caches, users can store relevant context without bloating LLM providers, drastically reducing computing costs.

### Agentic Workflows
Our core engine is built to provide a highly intelligent, adaptive, self-correcting agent, handling complex multi-step tasks, while being fully integrated into your codebase, it's a hands off approach to agentic coding.

---

### Other Features
  * Tab - Speed up your workflow with intelligent autocompletes.
  * Collections - Built a component that you want to reuse? Want to avoid having to reimplement it? Introducing Codebase Collections - a way to store, and reuse code across all of
    your projects. Collections allow users to easily copy and paste components via our collections widget in your workspace, or let our agents do it for you.
  * Collaborate - Codebase supports cross-agentic, cross-user collaboration.
  * Team Management - Allows organizations to easily manage users, delegate tasks, view progress etc...
  * Version control - Integrated directly with Git, you can commit, pull, merge, rollback all from Codebase, directly to and from your GitHub repositories.
